      02 / Guardrails
      
          
      MiniMax proposes. Python disposes.
      
          
      Each card below sends your input to the same Python functions the loop uses.
      
        
      

        
      
          
      
            
      Hyperparameter snapping
      
            
      The agent picks LoRA settings with start_training_model. Anything off the allowed grid is moved to the nearest safe value before training.
      
            
      
              
              
              
              
              
              
            
      
            
      
          
      

          
      
            
      Locked eval set
      
            
      Eval prompts and answers are canonicalized and hashed. Edit an answer and verify: the loop re-checks this hash before every scoring step and halts on a mismatch.
      
            
            
            
      
              
              
              
            
      
            
      
          
      

          
      
            
      Objective scorer
      
            
      Responses for the demo task are scored on seven strict-JSON checks against the locked answer, which never leaves the host.
      
            
            
            
      
            
            
            
      
            
      
          
      

          
      
            
      Adapter naming
      
            
      Saved adapters lead with what they do. Generic lead-ins are stripped and a short run-id tag keeps each name traceable to its log.

      03 / How it works
      
          
      One iteration, split by who decides
      
        
      
        
      
          
      
            
              
      StepThe agent proposesPython decides
      
                  
            
              
      
                create_evals
                Criteria for a correct answer and concrete {prompt, expected_output} pairs for the goal.
                Locks and SHA-256 hashes the set, baselines the untrained model, and regenerates a harder set once if the baseline already scores 0.85 or more.
              
      
              
      
                add_training_examples
                Targeted {prompt, completion} pairs aimed at the observed failures.
                Drops malformed pairs, normalizes completions to strict JSON and stacks examples across iterations.
              
      
              
      
                start_training_model
                Learning rate, rank, alpha, epochs and batch size.
                Snaps each value onto a fixed choice set, then trains: Unsloth on a GPU VM, or the mock backend.
              
      
              
      
                Score and judge
                MiniMax's retrain advisor says whether another round is worth it.
                Scores against the locked set. Llama 3.3 70B on DigitalOcean judges the outputs. Expected answers never leave the host.
              
      
              
      
                Continue or stop
                -
                Stops on target score, max iterations, patience, judge acceptance, user decline, cancellation, eval tampering, repeated training failure or an unavailable backend, and keeps the best adapter.
              
      
                  
          
      
        
      
      
      
    
      

    
      
      
      
        
      
          
      04 / Stack
      
          
      Models and moving parts
      
        
      
        
      
          
      
            
      
              Models
              
      RoleModel
      
              
                
      Specialized (default)unsloth/Phi-3-mini-4k-instruct
      
                
      Specialized (alternate)unsloth/Meta-Llama-3.1-8B-Instruct
      
                
      Planner, data generator, retrain advisorMiniMax-M2.7-highspeed
      
                
      LLM-as-judgellama3.3-70b-instruct on DigitalOcean
      
                
      Voice STT / TTS (TUI, optional)deepgram/nova-3 / cartesia/sonic-3
      
                    
            
      
          
      
          
      
            
      
              Training backends
              
      BackendWhat runs
      
              
                
      mockThe whole loop with no GPU, keys or network.
      
                
      remoteParamiko SSH/SFTP to a GPU VM; streams live train and eval logs.
      
                
      unslothIn-process Unsloth boundary (optional extra).

      uv run evolora demo --mock --iterations 2

      uv run uvicorn evolora.web.app:app --reload
      
        
      
        
      The last command serves this site and its API at http://127.0.0.1:8000. Add keys from .env.example for live MiniMax planning, the DigitalOcean judge, MongoDB history or GPU training.
